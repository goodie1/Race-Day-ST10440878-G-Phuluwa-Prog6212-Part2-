RaceDay API

Project Description



RaceDay API is an ASP.NET Core Web API designed to manage race events and related information.



Main Features

User registration and login

Authentication and role validation

Event management

Category management

Event enrollment

Race result management

Technologies Used

C#

ASP.NET Core Web API

SQL Server

ADO.NET

Swagger

Git and GitHub

Project Purpose



The purpose of this project is to demonstrate API development, database connectivity, authentication, and race event management.



Testing



Unit tests will be used to verify the application's functionality.
